# Model-driven JSON APIs / 模型驱动 JSON API

Run `racket examples/json-api/app.rkt` and retrieve `http://127.0.0.1:8080/openapi.json`. Declare operations with `api-operation`, optional input and output models, summary, operation ID and success status. The same declarations generate routes and OpenAPI 3.1 JSON. Input validation returns 400; invalid declared output returns 500. Path parameters are strings, JSON bodies are bounded after buffering. Use `make-api-app` with application middleware to protect routes. This example echoes validated input; it does not persist tasks. The current subset does not describe authentication, query parameters, alternate response statuses, streaming, multipart or arbitrary JSON schemas. Handler exceptions propagate. The documentation route is public unless protected by middleware. Do not expose internal models with sensitive fields.

运行 `racket examples/json-api/app.rkt`，访问 `http://127.0.0.1:8080/openapi.json`。使用 `api-operation` 声明接口、输入输出模型、摘要、operation ID 与成功状态码，由同一声明生成路由和 OpenAPI 3.1 JSON。输入验证失败返回 400，声明的输出验证失败返回 500。路径参数为字符串，请求体在缓冲后检查大小。通过应用中间件保护接口。本示例仅回显验证后的数据，不持久化任务。目前尚未覆盖认证声明、查询参数、多种响应状态、流式响应、multipart 或任意 JSON Schema。处理器异常向上传播。文档路由默认公开，需按应用需求保护，不应公开敏感内部模型。
