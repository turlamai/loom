# WebSocket transport / WebSocket 传输

`loom/live-websocket` provides `serve-live-websocket store registry #:origin origin`. It uses the existing Live Channel protocol and a dedicated loopback listener (default port 8081, path `/live`). Use a same-origin TLS reverse proxy in production; the configured Origin must match exactly. Cookies are secure by default. The connection handler checks the session and Origin, limits admitted channels and revalidates session ownership on each message. Default admitted channel capacity is 64 and the application reads at most 16385 bytes per message before rejecting oversized input. This does not guarantee a pre-allocation bound inside the protocol library. Deploy behind an edge with handshake, connection, message and timeout limits. Authorization is checked after upgrade in this initial adapter. No heartbeat, proactive server push or browser reconnect adapter yet. HTTP transport remains available. This implementation requires compilation and network-level verification before production use.
